# Focus Flow

A minimal Pomodoro-style focus timer with task tracking, built with plain HTML, CSS, and JavaScript.

## Features

- Work / Short Break / Long Break timer modes with automatic cycling
- Circular progress ring and live tab-title countdown
- Keyboard shortcuts: `Space` start/pause, `R` reset, `S` skip
- Task list with per-task pomodoro counts, saved to `localStorage`
- Audio chime when a session ends

## Usage

Open `index.html` in a browser — no build step or dependencies required.
